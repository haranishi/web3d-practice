# 練習02 — コロコロ・ライラック（玉転がしコイン集め）

Obsidian『02_notes/3Dゲーム制作/』の原則を全部実装に落とした1作目。
Three.js＋自前アーケード物理。ビルド不要・外部アセットゼロ（音もWebAudioで生成）。

## 動かし方
`index.html` をダブルクリックでブラウザで開くだけ（CDNのThree.jsを読むのでネット接続が要る）。

## 遊び方
- **WASD / 矢印キー**で移動、**スペース**でジャンプ、**R**でリスタート
- スマホ：左半分ドラッグ=移動、右半分タップ=ジャンプ
- コインを12枚ぜんぶ集めるタイムアタック。ベストタイムは保存される

## 物理の方式（自前アーケード物理）
- **高さマップ方式**：`groundHeightAt(x,z)`＝足元の最高面（箱の上 or 地面）。落下中にここへ達したら着地
- **横衝突**：円vs箱（closest point法）。ただし「ボール底が箱の天面より上」なら横衝突しない＝**飛び越え/上に乗れる**
- Rapier（本命の物理エンジン）はこの次のステップ。まず「物理が何をしてくれるか」を自前で1回書いて理解する、がノートの学習方針

## ✍️ 改造課題（写経→改造→自作の「改造」）
1. `ACCEL`/`JUMP_V`/`GRAV` を変えて「気持ちいい操作感」を探す（ゲームフィールの核心）
2. パレット5色を自分の配色に（`COL`）
3. コインを増やす・動くコインにする（`coinDefs`／`update`内で`u.x`を動かす）
4. 30秒タイムアタックモードに変える（`time`をカウントダウンに）
5. 動く床（箱の`x`をsinで往復→ボールに速度を伝える）
6. ゴースト機能：ベスト走行の軌跡を半透明ボールで再生（`pos`を毎フレーム記録）
7. **Rapier版に書き換える**（@dimforge/rapier3d-compat）→ ノート01の本命スタックへ
